# Personal Google Sheet structure

Create one native Google Sheet per user. Use a clean, readable style and freeze header rows. Include these tabs:

## Overview

Show the current book, next unread passage, total completed sessions, completed passages, and current streak only when dated sessions support it. Use formulas that reference the Reading Log and Progress tabs.

## Reading Log

Create a structured table with these columns:

1. Date
2. Book
3. Start Chapter
4. Start Verse
5. End Chapter
6. End Verse
7. Passage
8. Status
9. Time Spent
10. High Points Learned
11. Interests or Questions
12. Hebrew or Greek Insight
13. Source Links

Use a dropdown for Status with `Completed` and `Partial`. Preserve formulas, validation, and formatting when appending rows.

## Progress

Store the current book, next chapter, next verse, last completed passage, and last session date. Support changing books without deleting prior history.

## Preferences & Setup

Store the user's translation, target duration, selected starting book and passage, study emphasis, Sheet creation date, and any later preferences the user explicitly asks to save.

Do not include another person's identifiers, progress, interests, Sheet URL, or history. Do not share the Sheet unless its owner explicitly asks.
